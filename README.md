# RAG 기반 대시보드 생성 AI  

## 01 연구배경 및 주제  

- **연구 배경**  
  - 삼성전자 2014~2024년 감사보고서/사업보고서 데이터를 활용  
  - 금융 텍스트는 복잡하고 비정형 구조로 인해 정보 검색 및 활용이 어려움  

- **연구 주제**  
  - RAG 기반 QA 시스템 및 대시보드 생성  
  - 금융 보고서를 파싱·정규화·임베딩 후, LLM과 연계하여 **질의응답 + 시각화** 제공  

---

## 02 연구단계 별 진행상황  

### 1. 파싱 및 텍스트 정규화  
- 복잡한 HTML → 선형적 텍스트 변환  
- 불필요한 태그 제거, 숫자 표기 통일  
- 감사의견, 재무제표(재무상태표·손익계산서·포괄손익계산서·자본변동표·현금흐름표) 등 JSONL 저장  

### 2. 임베딩  
- 모델 후보: **E5, KoE5, OpenAI**  
- 평가 방법: 골든셋(50문항) 구축 + MRR 기반 성능 측정  
- 최종 선정: **E5** (Top10 정답 포함률 86.3%)  

### 3. ChromaDB 저장  
- Document + Embedding + Metadata 구조  
- 주요 메타데이터 필드:  
  - `company`, `year`, `section`, `section_path`, `content_type`  

### 4. 검색 및 QA  
- **1차**: 벡터 검색  
- **2차**: Reranker (Cross-Encoder) 적용  
- 메타데이터 기반 보정 점수(Boosting) 부여  
- LLM 프롬프트 설계:  
  - 환각 최소화  
  - JSON 출력 강제  
  - 출처 표기 의무화  

---

## 03 최종결과 및 시연  

- **QA 시스템**: Streamlit 기반 인터페이스 구현  
- **응답 구조**: `Answer + Sources + Context(JSON)`  
- **시연 예시**  
  - 질의: *"2024년 현금및현금성자산은?"*  
  - 응답: *"1조 6,537억 원"*  
    - 출처: 감사보고서 2024, 재무상태표 56기  

- **시각화 기능**  
  - 연도별 재무 데이터 라인차트  
  - 재무 비율 비교 바차트  

---

## 04 연구의의 및 한계  

- **의의**  
  - 한국어 금융 보고서에 특화된 RAG 시스템 구축  
  - 질의응답과 대시보드를 통합 제공  
  - 출처 기반 답변으로 신뢰도 강화  

- **한계**  
  - HTML 구조 비일관성으로 인한 파싱 어려움  
  - 도표·주석 기반 질의 정확도 보완 필요  
  - 외부 LLM 사용에 따른 비용 및 응답 속도 이슈
